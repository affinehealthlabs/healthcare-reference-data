### Affine NPPES Provider Data

A comprehensive, analytics-ready dimensional model of the National Plan and Provider Enumeration System (NPPES) containing 8M+ healthcare providers with National Provider Identifiers (NPI).

**Find it on Snowflake Marketplace:**
- Search for **"Affine Health Intelligence"**
- Category: **Health and Life Sciences**
- Listing: **Affine NPPES Provider Data**

**What's included:**
- Pre-built dimensional model optimized for BI tools and analytics
- Enriched taxonomy codes with NUCC specialty descriptions
- 18+ analytical views for common use cases
- Monthly updates aligned with CMS release schedule
